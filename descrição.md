PROJETO INTEGRADOR

REQUISITOS:
  APLICAÇÃO
    2 niveis de usuários (admin, user)

  GIT:
    Uso do gitflow  - pesquisar
    proibido
      commits genéricos
      branchs genericas
      commit direto na main
  a main só é atualizada através de PR (Pull request) com autorização de outro membro do time.

  QUALIDADE DO CÓDIGO:
    nomenclaturas de pastas
    numca deve ter espaço, todas as pastas devem ser nomeadas com um padrão, ou minúsculo ou capitalizado
    arquivos: arquivos .vue devem ter a primeira letra maiúscula
    demais arquivos podem ser nomeados com ou sem letras maiúsculas, o mais importante é o padrão
    lingua do código - não devem ser misturados, ou português, ou ingles
    CSS - padrões nas nomenclaturas das classes
    funções - padrão (arrow, nominal)

  IA:
    se fizer uso de IA deve conter ao menos um arquivo AGENTS.md

  O que será considerado também
    Manutenabilidade - facilidade de dar manutenção ao código
    Segurança - níveis de permissão e exposição de dados sensívies

  UX/UI
    responsividade
    facilidade de uso, dados claros e sem cara de produto genérico
